# 發布檢查清單

## 發布前

- [ ] `npx tsc -b` 與建置（`npm run build`）通過。
- [ ] 三份系統文件已更新（見 `commit-and-docs`）。
- [ ] 變更已 commit。

## 環境變數

- [ ] 新增的環境變數已在各環境（Production / Preview）設定。
- [ ] 前端變數（`VITE_`）與後端變數分清楚;機密只放後端。
- [ ] 環境變數異動後**務必重新部署**才會生效。
- [ ] 測試 / 除錯功能的開關變數,正式環境**不設**（確保關閉）。

## 排程器（如有）

- [ ] 排程器設定正確（URL、method、自訂 header、頻率）。
- [ ] 呼叫密鑰兩端一致。
- [ ] 確認排程實際被觸發,回應為 2xx。

## 部署後驗證

- [ ] 核心流程在正式環境實測一次。
- [ ] 檢查 log 無異常。

## 回報

- `deploy-notes.md`：記錄部署內容、環境變數異動、驗證結果。
- 部署是對外的不可逆動作 —— 有疑慮先向使用者確認。
