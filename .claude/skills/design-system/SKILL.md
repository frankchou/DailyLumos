# Daily Lumos 設計系統

> 本檔為**專案專屬**。Daily Lumos 是每日箴言抽卡 PWA,
> 視覺基調為「溫暖、典雅、靈性、安靜」—— 暖米底、燙金點綴。

## 色彩

| 用途 | 名稱 | 色碼 |
|------|------|------|
| 主背景 | warm.bg | `#FDF8F0` |
| 次背景 | warm.cream | `#FAF3E8` |
| 深底 | warm.dark | `#2C1F14` |
| 主金色 | gold | `#D4A853` |
| 亮金 | gold.light | `#F0D08A` |
| 暗金 | gold.dark | `#A8782A` |
| 琥珀 | amber | `#E8924A` |
| 主文字 | text-primary | `#3D2B1F` |
| 次文字 | text-secondary | `#8B6E5A` |
| 淺文字 | text-light | `#C4A882` |

- 金色用於點綴、強調、互動元素,**不大面積使用**。
- 新增顏色前先確認既有色票能否沿用;要擴充須與美術設計一致。

## 字型

| 用途 | 字體 |
|------|------|
| 襯線（標題、經文） | `Noto Serif TC`, Georgia |
| 無襯線（內文、UI） | `Noto Sans TC` |
| 裝飾（英文標題） | `Cinzel` |

## 陰影

- `card`：`0 8px 32px rgba(61,43,31,0.15)`
- `card-hover`：`0 16px 48px rgba(61,43,31,0.25)`
- `glow`：`0 0 20px rgba(212,168,83,0.4)` —— 金色光暈,用於聚焦元素。

## 動畫

- 既有：`pulse-glow`、`float`、`fade-in`、`slide-up`。
- 動畫要輕柔、緩和,符合「安靜靈修」的調性,避免突兀快速。
- 用 `framer-motion` 製作互動動畫。

## 品牌語氣（文字）

- 溫暖、親切、口語、有帶領感 —— 像陪伴,不像命令。
- 神的稱呼統一用「**主**」。
- 引導「先禱告、再抽卡」,把今日箴言定位為「主為你預備的禮物與方向」。
- 不說教、不沉重;簡短、留白、給人安定感。

## 排版原則

- 留白充足,行距寬鬆,讓畫面安靜。
- 圓角柔和（既有元件多用 `rounded-2xl` / `rounded-3xl`）。
- 響應式以**手機優先**;桌機為輔。
