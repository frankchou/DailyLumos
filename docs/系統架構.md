# Daily Lumos 系統架構

> 本文件說明「每日箴言抽卡」這套系統由哪些部分組成、各部分負責什麼，
> 以及資料如何在各部分之間流動。寫給想了解整體結構的人看，不需要工程背景。

---

## 一、這是什麼系統

**Daily Lumos** 是一個「每日箴言抽卡」網頁應用程式（PWA）。
使用者每天可以抽一張聖經經文卡，搭配 AI 解析、收藏功能，
並可設定每日提醒推播。可以「加到手機主畫面」像 App 一樣使用。

## 三、各部分負責什麼

### 1. 前端網頁 App（使用者看到、操作的畫面）

用 **React + TypeScript** 開發，由 **Vite** 打包，部署在 **Vercel**。
畫面樣式用 **Tailwind CSS**，動畫用 **framer-motion**，
App 內的狀態（誰登入了、今天抽了什麼卡）用 **zustand** 管理。

主要分成這幾類檔案：

| 分類 | 位置 | 負責 |
|------|------|------|
| 頁面 | `src/pages/` | 登入頁、抽卡頁、收藏頁、設定引導頁 |
| 元件 | `src/components/` | 卡片、彈窗、選單、教學、設定面板等可重複使用的畫面零件 |
| 狀態 | `src/store/` | 記住「目前登入者」與「卡片資料」 |
| 服務 | `src/services/` | 跟外部溝通：登入、資料庫讀寫、聖經經文、推播 |
| 工具 | `src/lib/`、`src/hooks/` | Firebase 連線、平台偵測、倒數計時等共用邏輯 |
| 資料 | `src/data/`、`src/constants/` | 聖經書卷清單、本地備援經文、主題設定 |

### 2. Firebase（雲端後台）

Google 提供的雲端服務，本系統用到三個部分：

- **Authentication（身分驗證）**：使用者用 Google 帳號登入。
- **Firestore（資料庫）**：儲存每位使用者的個人資料、抽過的卡片、推播設定。
- **Cloud Messaging（雲端推播通道）**：負責把推播訊息送到使用者裝置。

### 3. Vercel 後端函式（`api/` 資料夾）

部署在 Vercel 的小型後端程式，平常不執行，被呼叫時才跑：

- `api/analyze.ts`：收到一節經文，呼叫 AI 產生白話解析。
- `api/send-reminders.ts`：每日推播的發送中樞，判斷該推給誰、再送出。
- `api/test-push.ts`：測試用的推播發送（僅限測試環境，正式環境會自動關閉）。

### 4. cron-job.org 排程器

免費且準時的外部排程服務。本系統設定它**每分鐘**自動呼叫一次
`api/send-reminders.ts`，由後端去判斷此刻有哪些使用者該收到提醒。
選用每分鐘觸發，是為了把提醒誤差控制在 1 分鐘內。

> 專案內另保留一份 GitHub Actions 排程設定（`.github/workflows/push-reminders.yml`）
> 作為**備援**；它觸發頻率低且不保證準時，僅在 cron-job.org 異常時兜底，
> 重複呼叫不會造成重複推播（後端有當日去重機制）。

### 5. 聖經經文資料來源

- 線上：`bible-api.com` 取得完整經文。
- 備援：當線上服務取不到時，使用 `src/data/bibleVersesLocal.ts` 內建的本地經文，確保一定抽得到卡。

### 6. 瀏覽器推播服務（Service Worker）

`public/firebase-messaging-sw.js` 是一支在瀏覽器背景執行的小程式。
即使網頁沒開著，它也能收到推播並跳出通知。

## 四、資料怎麼流動（兩個典型例子）

### 例子 A：使用者抽一張卡

```
使用者按「抽卡」
   → 前端隨機選一卷書、一節經文
   → 向 bible-api.com 取得經文（失敗則用本地備援）
   → 畫面立刻顯示卡片（先讓使用者看到）
   → 背景把卡片寫入 Firestore 資料庫、更新「今天已抽卡」
```

### 例子 B：每日提醒推播

```
cron-job.org 每分鐘呼叫 api/send-reminders.ts
   → 後端算出現在的台灣時間
   → 從 Firestore 撈出所有「有開啟推播」的使用者
   → 逐一判斷：提醒時間到了嗎？今天抽過卡了嗎？今天通知過了嗎？
   → 對符合條件的人，透過 Firebase 推播通道送出提醒
   → 使用者裝置的 Service Worker 收到並跳出通知
```

（推播的詳細判斷規則請見《系統機制》文件。）

## 五、技術一覽

| 項目 | 採用技術 |
|------|----------|
| 前端框架 | React 18 + TypeScript |
| 打包工具 | Vite 5 |
| 樣式 | Tailwind CSS 3 |
| 動畫 | framer-motion |
| 前端狀態管理 | zustand |
| 登入 / 資料庫 / 推播 | Firebase（Auth、Firestore、Cloud Messaging）|
| 後端函式 | Vercel Serverless Functions |
| 自動排程 | cron-job.org（每分鐘觸發；GitHub Actions 為備援）|
| AI 解析 | Claude API |
| 部署平台 | Vercel |
| 程式碼倉庫 | GitHub（frankchou/DailyLumos）|
