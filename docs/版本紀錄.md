## 2026-05-16

### 11:23 — 提醒時間開放到「每分鐘」
- **更新內容**：把每日提醒時間的設定從原本的「整點 / 半點」（48 格半小時）
  開放到可精確設定**任一分鐘**（例如 08:17、21:45）。設定畫面改用「時 / 分」
  兩個選單組合。後端判斷時間本來就是用精確的「時＋分」比對，故不需更動；
  此次純粹解除前端 UI 的半小時限制 —— 該限制是 GitHub Actions 每 30 分鐘
  排程時代的遺留，改用每分鐘排程後已無必要。
- **更新檔案**：`src/components/ReminderSettings.tsx`、
  `src/services/firestoreService.ts`、`docs/系統機制.md`
- **Git 紀錄**：`8bb38c6`

### 11:12 — 移除 GitHub Actions 推播排程
- **更新內容**：改用 cron-job.org 後，移除原本的 GitHub Actions 推播排程。
  GitHub Actions 達不到所需的準時度，僅留作備援價值有限、又會在出問題時
  寄失敗通知信，故移除。cron-job.org 成為唯一的排程器。
- **更新檔案**：`.github/workflows/push-reminders.yml`（刪除）、`docs/系統架構.md`
- **Git 紀錄**：`de3c504`

### 11:09 — 改用每分鐘精準排程，提醒誤差縮到 1 分鐘內
- **更新內容**：把每日提醒的排程器改用 **cron-job.org**，每分鐘觸發一次，
  讓推播誤差控制在 1 分鐘內。原本使用的 GitHub Actions 排程最小只能每 5 分鐘、
  且整點常被延遲甚至直接丟棄，無法準時。同時把「補送視窗」從 90 分鐘縮短為 10 分鐘
  —— 每分鐘呼叫下，提醒時間一到就推，視窗僅作為偶發呼叫失敗的安全網。
  GitHub Actions 排程保留為備援角色。
- **更新檔案**：`api/send-reminders.ts`、`.github/workflows/push-reminders.yml`
- **Git 紀錄**：`045efb2`

### 11:04 — 將推播排程錯開整點以提高觸發率
- **更新內容**：把 GitHub Actions 推播排程的觸發時間，從整點 :00 / :30
  錯開到冷門的 :07 / :37。GitHub 在每個整點負載最重，:00 / :30 的排程
  最常被延遲或丟棄，錯開可提高實際被觸發的機率。
  （註：稍後此排程已改為備援角色，主排程改用 cron-job.org。）
- **更新檔案**：`.github/workflows/push-reminders.yml`
- **Git 紀錄**：`e647e80`

### 10:43 — 推播提醒文案改寫成溫暖引導語氣
- **更新內容**：把每日提醒推播的文字全部重寫。語氣改為溫暖、親切、口語、帶領感，
  每一則都引導使用者「**先禱告、再抽卡**」，並把今日箴言定位成主為你預備的禮物與方向。
  文案從原本 4 則擴充為 6 則，每天依日期自動輪替一則。
- **更新檔案**：`api/send-reminders.ts`
- **Git 紀錄**：`b82986e`

### 10:26 — 修正每日推播排程一直失敗的問題
- **更新內容**：修正 GitHub Actions「每 30 分鐘自動發送提醒」的排程持續失敗、
  且每半小時寄一封失敗通知信的問題。原因是呼叫後端用的網址設定變數沒有填，
  導致呼叫的網址不完整。改成把正式網址直接寫死在排程設定中（網址非機密），
  並在密鑰未設定時顯示清楚易懂的錯誤訊息，方便排查。
- **更新檔案**：`.github/workflows/push-reminders.yml`
- **Git 紀錄**：`5930940`

### 03:29 — 新增「加到主畫面」教學與每日推播提醒系統
- **更新內容**：一次新增兩大功能。
  （1）**加到主畫面教學**：手機版會自動偵測 iOS 或 Android，
  顯示對應的三步驟安裝說明；電腦版不顯示。
  （2）**每日抽卡推播提醒系統**：使用者可自行開關推播、設定每日提醒時間（可細到半小時）；
  系統會在指定時間、當天還沒抽卡的情況下推播提醒；若當天已抽卡則不打擾。
  包含通知設定畫面、推播發送後端、每 30 分鐘觸發的自動排程，
  以及一個僅限測試環境、正式環境自動隱藏的「發送測試通知」功能。
- **更新檔案**：`.env.example`、`.github/workflows/push-reminders.yml`、
  `api/send-reminders.ts`、`api/test-push.ts`、`public/firebase-messaging-sw.js`、
  `src/components/InstallGuide.tsx`、`src/components/ReminderSettings.tsx`、
  `src/components/UserMenu.tsx`、`src/lib/firebase.ts`、`src/lib/platform.ts`、
  `src/services/firestoreService.ts`、`src/services/pushService.ts`
- **Git 紀錄**：`45c27f4`
