# 功能導引教學（Onboarding Tutorial）— 測試計畫

功能代號：`onboarding-tutorial`
撰寫角色：QA 測試工程師
上游文件：`requirements.md`（驗收標準 AC-1～AC-28、邊界 EX-1～EX-12）、`ux-flow.md`
測試環境限制：QA 在 CI 環境無法做互動式瀏覽器點擊；本計畫的瀏覽器互動案例
須由開發者在 dev 環境（含手機 / 桌機 / PWA）人工執行。

每個案例格式：**前置條件 → 操作步驟 → 預期結果**。

---

## 一、正常路徑

### TC-N1 手機首次登入自動教學（AC-1, AC-10）
- 前置：全新帳號（`users` 文件無 `tutorialSeenMobile`）；手機瀏覽器；未安裝 PWA。
- 步驟：登入 → 等抽卡頁與當日卡片載入完成。
- 預期：載入結束後自動升起遮罩，進入手機版站①，依序 7 站，內容與 requirements 第四節一致。

### TC-N2 桌機首次登入自動教學（AC-2, AC-11）
- 前置：全新帳號（無 `tutorialSeenDesktop`）；桌機瀏覽器（視窗 ≥ 1024px）。
- 步驟：登入 → 等載入完成。
- 預期：自動升起遮罩，進入桌機版站①，依序 5 站。

### TC-N3 逐站前進到完成（AC-27, AC-18, AC-19）
- 前置：自動教學已啟動。
- 步驟：每站點「下一步」，最後一站點「完成」。
- 預期：站間 spotlight 平移；最後一站按鈕為「完成」；結束後遮罩消失；
  對應旗標（`tutorialSeenMobile` / `tutorialSeenDesktop`）寫入 `true`。

### TC-N4 上一步回看（AC-27）
- 前置：教學進行到站③以後。
- 步驟：點「上一步」。
- 預期：回到前一站，spotlight 反向平移；第 1 站不顯示「上一步」。

### TC-N5 手動入口開啟（手機）（AC-5, AC-7）
- 前置：任意已登入手機使用者。
- 步驟：點右上角頭像 → UserMenu 出現「功能導引」→ 點它。
- 預期：選單先收合 → 啟動手機版教學。

### TC-N6 手動入口開啟（桌機）（AC-6, AC-7）
- 前置：任意已登入桌機使用者。
- 步驟：點 Sidebar 底部 UserSection → 彈出選單 → 確認「功能導引」位於「登出」之上 → 點它。
- 預期：選單先收合 → 啟動桌機版教學。

### TC-N7 回訪使用者重看（AC-8, AC-20）
- 前置：`tutorialSeenMobile`/`Desktop` 已為 `true` 的使用者。
- 步驟：經入口按鈕開啟教學 → 走完或略過。
- 預期：教學正常顯示；結束後旗標維持 `true`、不被改動（手動開啟不寫旗標）。

## 二、邊界案例

### TC-B1 已看過教學不自動顯示（AC-3）
- 前置：`tutorialSeenMobile`=`true`（手機）。
- 步驟：重新登入。
- 預期：不自動彈出教學。

### TC-B2 手機已安裝 PWA → 6 站（AC-14, EX-2）
- 前置：手機以 PWA standalone 模式開啟；全新帳號。
- 步驟：登入觸發自動教學。
- 預期：站⑦「加到主畫面」不存在；共 6 站；進度顯示 1/6～6/6；站⑥為最後一站、按鈕「完成」。

### TC-B3 手機未安裝 → 含第⑦站（AC-13）
- 前置：手機瀏覽器分頁（非 standalone）。
- 步驟：觸發教學。
- 預期：含站⑦「加到主畫面」，共 7 站。

### TC-B4 桌機不出現推播 / 加到主畫面站（AC-12）
- 前置：桌機。
- 步驟：跑完桌機教學。
- 預期：5 站皆無「每日提醒設定」「加到主畫面」。

### TC-B5 卡片未 render 不啟動（AC-4, EX-1）
- 前置：模擬卡片載入緩慢（`isSyncing` 長時間為 true）。
- 步驟：登入。
- 預期：等待期間顯示正常抽卡頁，不出現遮罩 / 挖空空白；載入完成後才啟動。

### TC-B6 新使用者未抽卡時的「卡片互動」站（AC-15, AC-17）
- 前置：全新帳號、尚未抽卡。
- 步驟：教學走到站③。
- 預期：挖空整個卡片區域容器（`data-tutorial="card-area"`），不嘗試挖翻面 / 原文子元素；行為與已抽卡時一致。

### TC-B7 「卡片互動」站文字（AC-16）
- 步驟：檢視站③說明文字。
- 預期：文字為「抽完卡後，點卡片可翻面看 AI 解析、看整章原文」。

### TC-B8 倒數計時站（新使用者未抽卡）
- 前置：全新帳號、未抽卡（真實 CountdownTimer 不存在）。
- 步驟：教學走到「倒數計時」站。
- 預期：spotlight 內顯示展示版倒數計時（固定 23:59:59），進度不跳號。

### TC-B9 自動教學在「我的卡片冊」頁觸發（EX-12, AC 顯示時機）
- 前置：全新帳號；登入後預設落在 collection 頁。
- 步驟：登入。
- 預期：先靜默切回抽卡頁，再啟動教學。

### TC-B10 同帳號手機看過、桌機首次（AC-21, EX-11）
- 前置：`tutorialSeenMobile`=`true`、`tutorialSeenDesktop` 未設定。
- 步驟：在桌機登入同帳號。
- 預期：自動顯示桌機版教學。

### TC-B11 既有老使用者首次登入（EX-6）
- 前置：功能上線前已存在的帳號，`users` 文件無教學旗標欄位。
- 步驟：登入。
- 預期：視為未看過，自動教一次。

## 三、錯誤路徑 / 降級

### TC-E1 旗標寫入 Firestore 失敗（AC-22, EX-4）
- 前置：模擬 `markTutorialSeen` 寫入失敗（離線 / 權限）。
- 步驟：跑完自動教學。
- 預期：教學照常結束、遮罩消失、App 完全可用；不顯示錯誤提示給使用者；console 記錄錯誤。

### TC-E2 旗標讀取失敗 / 欄位不存在（EX-5, FR-6.7）
- 前置：模擬 `getTutorialFlags` 讀取拋錯。
- 步驟：登入。
- 預期：視為未看過，正常啟動自動教學。

### TC-E3 桌機站① 目標元素不存在時的降級
- 前置：桌機教學站①目標 `sidebar-nav`。
- 步驟：教學啟動進站①。
- 預期（規格期望）：spotlight 對位到 Sidebar 導覽項目並顯示說明卡。
- 實作降級行為：若目標 DOM 不存在，TutorialOverlay 輪詢約 1.5s 後 `next()` 跳過該站。

## 四、狀態與時序

### TC-S1 教學進行中登出（EX-7）
- 前置：教學進行中。
- 步驟：（透過教學以外途徑）觸發登出 / session 失效。
- 預期：教學遮罩、說明卡、展開的選單一併移除，不殘留在登入畫面。

### TC-S2 略過導引（中途關閉）（AC-25, EX-3）
- 前置：教學任一站。
- 步驟：點說明卡右上「略過導引」。
- 預期：遮罩消失；若為自動顯示則寫入旗標；若手機選單已展開則先收合。

### TC-S3 站⑤→⑥ 自動展開選單（D3, EX-10）
- 前置：手機教學走到站⑤（頭像）。
- 步驟：點「下一步」。
- 預期：使用者選單自動展開，spotlight 對位到「每日提醒設定」。

### TC-S4 站⑥→⑤ 上一步收合選單（ux-flow 第六節）
- 前置：手機教學在站⑥。
- 步驟：點「上一步」。
- 預期：選單收合，回到站⑤介紹頭像入口情境。

### TC-S5 站間轉場連點防呆（ux-flow 第三節）
- 前置：教學任一站。
- 步驟：spotlight 轉場進行中快速連點「下一步」。
- 預期：不出現 spotlight 錯位 / 進度跳號。

### TC-S6 視窗 resize / scroll 重新對位（EX-8）
- 前置：教學進行中。
- 步驟：縮放視窗或捲動頁面。
- 預期：挖空框與說明卡跟隨目標重新對位，不挖到錯誤位置。

## 五、遮罩互動

### TC-M1 遮罩覆蓋與挖空（AC-23）
- 預期：全畫面被半透明暖黑遮罩覆蓋；僅當前站目標被挖空、正常顯示。

### TC-M2 底層不可誤觸（AC-24）
- 步驟：教學進行中點挖空框外的底層按鈕。
- 預期：底層 App 按鈕無反應。

### TC-M3 點遮罩暗處不關閉（FR-7.4）
- 步驟：點遮罩暗處。
- 預期：教學不關閉。

### TC-M4 結束後遮罩完全消失（AC-26）
- 步驟：完成或略過教學。
- 預期：遮罩淡出消失，App 回到可正常操作狀態。

### TC-M5 說明卡不出血、不遮目標（AC-28）
- 步驟：逐站檢視，特別是貼邊目標（手機底部導覽、選單內項目）。
- 預期：說明卡不超出畫面、不遮住挖空目標。
