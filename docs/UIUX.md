## 1. 設計哲學

### 核心關鍵字
> **溫暖 · 光 · 心靈**

Daily Lumos 的設計語言來自「黎明第一道光」的意象——
不是刺眼的強光，而是柔和透過窗簾的晨光，
讓人感覺被接納、平靜，帶著一點期待開始新的一天。

### 三大設計原則

| 原則 | 說明 |
|------|------|
| **Warmth 溫暖** | 暖色調為主，圓角、柔和陰影，避免冷硬感 |
| **Luminous 發光** | 光效、漸層、輕微的 glow 效果，彷彿卡片本身在發光 |
| **Sacred Space 神聖感** | 留白充足，字體優雅，每個互動都是一個小儀式 |

### 4.2 抽卡頁面 (DrawPage)

#### 版面配置
```
┌──────────────────────────┐
│      [Logo + 日期]        │  頂部 Header (80px)
│                          │
│    ┌──────────────┐      │
│    │              │      │
│    │   卡片區域    │      │  主要內容區 (彈性)
│    │   (抽前/後)  │      │
│    │              │      │
│    └──────────────┘      │
│                          │
│   [今日感言 / 倒數計時]    │  底部資訊區 (80px)
│                          │
│  ──────── NavBar ──────── │  導覽列 (64px)
└──────────────────────────┘
```

#### 抽卡前狀態
```
卡片背面:
  - 尺寸: 280px × 400px，圓角 24px
  - 背景: 深棕漸層 + 金色幾何花紋（SVG 圖案）
  - 中央: Daily Lumos Logo（發光效果）
  - 下方: 「點擊抽取今日箴言」

抽卡按鈕:
  - 圓形按鈕 72px
  - 背景: 金色漸層
  - 圖示: 光芒/星形
  - 動畫: 脈衝 glow（pulse animation，2s loop）
  - 懸停: scale(1.08) + glow 增強
```

#### 抽卡中動畫
```
1. 按鈕縮小消失 (200ms)
2. 卡片向上浮起 + 輕微旋轉 (300ms)
3. 卡片沿 Y 軸翻轉 180° (600ms, ease-in-out)
   - 前半：卡片背面消失
   - 後半：主題卡片出現
4. 卡片落定 + 發光粒子效果 (400ms)
5. 文字淡入 (300ms)

總計: ~1.8 秒動畫
```

#### 抽卡後狀態（今日卡片）
```
卡片正面:
  - 尺寸: 280px × 400px，圓角 24px
  - 背景: 對應主題漸層
  - 頂部: 主題名稱（中英文小字）
  - 中段: 箴言全文（Noto Serif TC，白色/深色依主題）
  - 底部: 章節標示 + 日期
  - 卡片邊緣: 細金框線（1px, rgba(255,255,255,0.3)）
  - 陰影: 主題色 glow shadow

底部動作區:
  - [分享] 按鈕（P2）
```

## 5. 互動設計

### 5.1 微互動清單

| 元素 | 互動 | 動畫 |
|------|------|------|
| 抽卡按鈕（待抽） | - | pulse glow, 2s loop |
| 抽卡按鈕 hover | 懸停 | scale 1.08, glow 增強, 150ms |
| 抽卡按鈕 press | 點擊 | scale 0.95, 100ms |
| 卡片翻轉 | 抽卡觸發 | Y 軸 rotateY(180deg), 600ms |
| 卡片冊縮略圖 hover | 懸停 | scale 1.03, shadow 增強, 200ms |
| Modal 開啟 | 點擊縮略圖 | scale + fade in, 250ms |
| Modal 關閉 | 點擊遮罩 | scale + fade out, 200ms |
| Page 切換 | Tab 點擊 | slide + fade, 200ms |

### 5.2 倒數計時設計
```
位置: 抽卡後，卡片下方
格式: 「距明日新箴言 HH:MM:SS」
樣式: 淡棕小字，每秒更新
午夜重置: 顯示短暫的「新的一天，新的光✦」過場
```

### 5.3 首次使用引導
```
第一次開啟 App:
  1. Splash 畫面: Logo 淡入 (1.5s)
  2. 副標題淡入: "每天一句光，照亮前行的路" (0.8s)
  3. 自動進入抽卡頁
  4. 卡片背面有輕微「快點我」提示動畫
```

## 7. 無障礙設計 (Accessibility)

- 所有互動元素的 ARIA label
- 顏色對比度符合 WCAG AA 標準（文字對背景 ≥ 4.5:1）
- 卡片翻轉動畫遵循 `prefers-reduced-motion`
- 字體大小基準 16px，避免使用 < 12px 文字
