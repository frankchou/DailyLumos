## 1. 產品概述

### 1.1 產品名稱
**Daily Lumos**

> *Lumos* — 源自哈利波特「照明咒」，象徵「讓光照進來」。每日一句聖經箴言，如晨光照亮心靈。

### 1.2 產品定位
一款以「每日抽箴言卡」為核心的心靈輕應用，使用者每天抽取一張聖經箴言卡，收集屬於自己的靈性卡片冊，在忙碌生活中留下一片寧靜與光。

### 1.3 目標使用者
- 有信仰基礎或對靈性成長感興趣的使用者
- 習慣日記、靜思、晨間儀式的人
- 喜歡「卡片收集」遊戲化設計的輕度使用者
- 年齡層：18–45 歲

### 1.4 核心價值主張
> 「每天只需一次，讓一句話陪伴你度過這一天。」

## 2. 目標與成功指標

### 2.1 業務目標
- 打造日常使用習慣，提升 Day-7 留存率
- 透過卡片收集機制增加使用者黏著度
- 建立溫暖、有質感的心靈品牌形象

### 2.2 成功指標 (KPIs)
| 指標 | 目標值 |
|------|--------|
| Day-1 留存率 | ≥ 60% |
| Day-7 留存率 | ≥ 30% |
| 每日打開率 | ≥ 40% (已安裝用戶) |
| 卡片冊平均收集數 | 7 天後 ≥ 5 張 |
| 卡片分享率 | ≥ 15% |

## 3. 核心功能需求

### 3.1 每日抽箴言卡 (Daily Draw)

**優先級**: P0 — 核心功能

#### 規則
- 每位使用者每個曆日（00:00 重置）只能抽取一次
- 抽取來源：聖經箴言章節，透過 [Bible-api.com](https://bible-api.com) 取得
- 每次抽取為隨機箴言節次（Proverbs 1:1 ~ 31:31）
- 抽取後顯示完整的箴言卡片

#### 使用者流程
1. 打開 App → 看到「今日抽卡」主畫面
2. 若今日尚未抽卡 → 顯示「抽卡」按鈕（帶動態光效）
3. 點擊按鈕 → 卡片翻轉動畫 → 顯示今日箴言
4. 若今日已抽卡 → 顯示今日卡片 + 倒數計時（距明日重置）

#### 卡片內容
- 箴言原文（繁體中文）
- 章節標示（例：箴言 3:5）
- 對應主題背景（詳見 Section 4）
- 日期戳記

---

### 3.2 卡片冊 (Card Collection)

**優先級**: P0 — 核心功能

#### 功能描述
- 顯示使用者歷次抽卡的所有箴言卡片
- 以時間倒序排列（最新在前）
- 支援捲動瀏覽
- 點擊單張卡片可放大檢視

#### 卡片資訊
- 箴言全文
- 章節來源
- 抽卡日期
- 卡片背景主題名稱

---

### 3.3 卡片背景主題系統 (Card Theme)

**優先級**: P1

根據箴言章節或關鍵字，自動配對對應的溫暖背景主題：

| 主題名稱 | 觸發條件（章節範例） | 視覺風格 |
|----------|---------------------|----------|
| 晨曦 (Dawn) | 第 1–5 章（智慧開端） | 淡橙、金黃漸層 |
| 甘露 (Dew) | 第 6–10 章（勤勞警醒） | 薄荷綠、珍珠白 |
| 溫泉 (Spring) | 第 11–15 章（義人之路） | 粉橘、珊瑚 |
| 星光 (Starlight) | 第 16–20 章（謙遜信靠） | 深藍、銀紫漸層 |
| 暖燈 (Lantern) | 第 21–25 章（王道智慧） | 琥珀、暖棕 |
| 彩虹 (Rainbow) | 第 26–31 章（才德婦人） | 柔和彩虹漸層 |

### 3.4 卡片分享 (Share)

**優先級**: P2

- 一鍵將今日箴言卡片匯出為圖片
- 支援分享至社群媒體或儲存至相簿
- 圖片包含 Daily Lumos 浮水印 Logo

## 4. 非功能性需求

### 4.1 效能
- 首屏載入時間 < 2 秒
- API 回應逾時 < 5 秒，需有 Fallback（本地快取）

### 4.2 離線能力
- 已抽取的卡片冊需在離線狀態下可瀏覽
- 今日卡片若已抽取，離線也可查看

### 4.3 資料儲存
- 使用者卡片資料儲存於本地（LocalStorage / IndexedDB）
- MVP 階段不需帳號系統

### 4.4 語言
- 繁體中文介面
- 聖經文本：繁體中文（Bible-api.com 支援 `cunpss` 版本）

### 4.5 平台
- MVP：Web App（手機優先 RWD）
- 後續考慮：PWA 離線安裝

## 6. 風險與假設

| 風險 | 影響 | 緩解措施 |
|------|------|----------|
| Bible-api.com 服務不穩定 | 無法取得箴言 | 本地預存所有箴言節次作為 Fallback |
| 使用者忘記每日打開 | 習慣養成困難 | 設計強烈的每日儀式感（動畫、視覺）|
| 卡片主題不符使用者預期 | 體驗落差 | 允許手動切換主題（P2） |
